# FileSystemAnalyzer

Десктопное приложение на C++17 и Qt для анализа содержимого каталогов: размеры, крупнейшие и новые файлы, распределение по категориям и расширениям, поиск возможных дубликатов.

## Возможности

- Сканирование одного или нескольких каталогов, с рекурсией или без
- Общее количество и суммарный размер файлов
- Топ-K крупнейших файлов, фильтр по порогу размера
- Новые файлы после заданной даты
- Статистика по категориям (документы, изображения, видео, аудио, архивы) и по расширениям
- Поиск возможных дубликатов: по имени, по размеру или по имени и размеру
- Вывод отчёта в интерфейс, в консоль и в файл истории

## Архитектура

Каждый вид анализа реализует интерфейс `IAnalysis`, каждый способ вывода - интерфейс `IReporter`. Новый анализ или формат отчёта добавляется отдельным классом без изменения остального кода.

```
FileScanner ──► ScanResult ──► Analyzer ──► [IAnalysis ...] ──► ReportChunk ──► [IReporter ...]
                                               │                                     │
                     CountSize, Biggest, Newest,                      ConsoleReporter,
                     Categories, Exts, Dups                           HistoryReporter
```

| Файл | Назначение |
|---|---|
| `file_scanner.*` | Обход файловой системы, сбор `FileInfo` |
| `analyzer.*` | Запуск выбранных анализов |
| `ianalysis.*`, `analysis_base.*` | Интерфейс и базовый класс анализа |
| `count_size.*`, `biggest.*`, `newest.*`, `category_analysis.*`, `exts.*`, `dups.*` | Конкретные анализы |
| `ireporter.*`, `console_reporter.*`, `history_reporter.*`, `report_printer.*` | Вывод отчётов |
| `config.h` | Параметры запуска (`AppConfig`) |
| `input_guard.*` | Проверка пользовательского ввода |
| `mainwindow.*` | Графический интерфейс на Qt Widgets |
| `tests.*` | Тесты |

## Сборка

Нужны CMake >= 3.16, компилятор с поддержкой C++17 и Qt 5 или Qt 6 (Widgets).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Стек

C++17, Qt Widgets, CMake, STL (`<filesystem>`, `<chrono>`)
